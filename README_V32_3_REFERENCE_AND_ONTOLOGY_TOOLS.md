# V32.3 Reference and Ontology Tools

This package is a **test/diagnostic add-on** for `rat-paxinos-brainglobe-builder` after V32.2.

It assumes the V32.2 builder already produced and installed the correctly oriented atlas:

```text
paxinos_watson_rat_40um
shape: [608, 286, 409]
orientation: PIL
ABBA display fix: perm=(1,2,0)
```

## Why this exists

V32.2 fixed the display orientation. It did **not** solve the visual/reference problem.

Current remaining issues:

1. `reference.tiff` is still a synthetic label-edge image, not a real anatomical reference.
2. ABBA shows `reference` and `borders`, but the current reference itself already looks like label borders.
3. The atlas should be tested with a real anatomical background, ideally SIGMA first.
4. The automatically built acronyms and ontology need a separate audit before serious publication-level use.

## Files in this package

Copy these files into your project root:

```text
RUN_V32_3_BUILD_SIGMA_REFERENCE_TEST_ATLAS.bat
RUN_V32_3_BUILD_NULL_REFERENCE_DEBUG_ATLAS.bat
RUN_V32_3_ONTOLOGY_AUDIT.bat
src/v32_3_build_sigma_reference_test_atlas.py
src/v32_3_build_null_reference_debug_atlas.py
src/v32_3_ontology_audit.py
```

## 1. SIGMA anatomical reference test atlas

Run:

```bat
RUN_V32_3_BUILD_SIGMA_REFERENCE_TEST_ATLAS.bat
```

It creates and installs this separate atlas:

```text
paxinos_watson_rat_40um_sigma_reference_test
```

It does **not** overwrite:

```text
paxinos_watson_rat_40um
```

Expected SIGMA file location, with recursive fallback search:

```text
data/raw/bluebrainheadmodels/SIGMA_Anatomical_Brain_Atlas.nii
```

Outputs:

```text
reports/v32_3_sigma_reference_test/v32_3_sigma_reference_test_report.txt
reports/v32_3_sigma_reference_test/v32_3_sigma_reference_test_report.json
reports/v32_3_sigma_reference_test/sigma_reference_test_preview_panels.png
```

ABBA test:

```text
Open atlas: paxinos_watson_rat_40um_sigma_reference_test
```

Look for:

```text
reference = anatomical background
borders   = Paxinos label border overlay
```

If the reference is shifted, distorted, empty, or biologically implausible, do **not** promote it into the main atlas.

## 2. NULL reference debug atlas

Run:

```bat
RUN_V32_3_BUILD_NULL_REFERENCE_DEBUG_ATLAS.bat
```

It creates and installs:

```text
paxinos_watson_rat_40um_null_reference_debug
```

This atlas has:

```text
reference.tiff = all zeros
annotation.tiff = unchanged
```

Purpose:

```text
If ABBA still displays atlas content when reference is empty and borders are hidden,
then the remaining visible content is ABBA display behavior, not reference.tiff.
```

## 3. Ontology/acronym audit

Run:

```bat
RUN_V32_3_ONTOLOGY_AUDIT.bat
```

It writes:

```text
reports/v32_3_ontology_audit/v32_3_ontology_audit_summary.txt
reports/v32_3_ontology_audit/annotation_ids_missing_structures.csv
reports/v32_3_ontology_audit/structures_without_voxels.csv
reports/v32_3_ontology_audit/parent_path_integrity_flags.csv
reports/v32_3_ontology_audit/duplicate_acronym_flags.csv
reports/v32_3_ontology_audit/duplicate_name_flags.csv
reports/v32_3_ontology_audit/suspicious_autogenerated_label_flags.csv
reports/v32_3_ontology_audit/manual_ontology_review_template.csv
```

Important:

- Critical machine-integrity problems are things like missing structure IDs or broken parent paths.
- Duplicate acronym/name flags are review queues, not automatic failures.
- Do not auto-correct ontology. Curated overrides should be applied only after review.

## Recommended order

```text
1. RUN_V32_3_BUILD_NULL_REFERENCE_DEBUG_ATLAS.bat
2. Check in ABBA whether hidden reference/borders truly disappear
3. RUN_V32_3_BUILD_SIGMA_REFERENCE_TEST_ATLAS.bat
4. Check in ABBA whether SIGMA gives a usable anatomical background
5. RUN_V32_3_ONTOLOGY_AUDIT.bat
6. Review reports before integrating anything into the main builder
```

## What this package does not do

It does not yet integrate SIGMA into the stable atlas.
It does not smooth or edit Paxinos labels.
It does not automatically correct acronyms or ontology.
It does not pretend a test reference is final validation. Society has enough confidence tricks already.
